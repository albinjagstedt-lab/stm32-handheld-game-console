STM32 HANDHELD GAME CONSOLE

A Game console project based on STM32G431KB and ST7735 lcd display.

My plan is to create a handheld game console running in full color on AA batteries that will hopefully have access to 2-3 different simple games (depends on how much can fit on the 32kb SRAM). I have buttons for Left, Right, A, B and Start. The final design will feature a 3d printed casing and my goal is to keep it as small as possible using the components i have.
